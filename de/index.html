Eine Farbe,
sieben Stufen.

Tono ist ein Rätsel über Töne. Jede Röhre fasst vier Einheiten, und alle Stücke sind Stufen einer Farbe: eine Leiter von hell nach dunkel. Tippe eine Röhre an, dann eine zweite; stimmen die oberen Töne überein, wird gegossen. Enthält jede Röhre nur noch einen Ton, ist das Level geschafft.

Kostenlos. Funktioniert offline. Kein Konto.
